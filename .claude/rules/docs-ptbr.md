# Documentação (`docs/`)

- Escrever em **português**; termos técnicos e identificadores de código permanecem em inglês.
- Decisão técnica nova ⇒ novo ADR (skill `new-adr`) e atualização de `docs/adr/README.md`. Não contradizer ADR aceito sem ADR substituto.
- Mudança de status de história ⇒ atualizar `docs/plan/progress.md`. Somente o usuário marca como **Aprovada**.
- Mudança em RF, regra ou história ⇒ manter `docs/plan/traceability.md` consistente.
- Decisão do usuário sobre D-XX ⇒ skill `resolve-decision`.
- Commits de documentação: `docs(<scope>): …` (Conventional Commits).
